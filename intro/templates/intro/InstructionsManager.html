📐 Cost Calculations

1. Assuming both parties delegate to a {{ agent_1 }}, here is how to calculate the expected costs:

Expected delegation cost to {{ agent_1 }} (conditional on facing a {{ agent_1 }} counterpart):

Expected(Delegation Cost to {{ agent_1 }}) = 0.75 × (TC) + 20
How?
Expected(Delegation Cost to {{ agent_1 }}) =
= P(Full TC) x Full TC + P(Halved TC) x Halved TC + Human Agent Base Cost =
= 0.5 x (Full TC) + 0.5 x (0.5 x Full TC) + Human Agent Base Cost =
= 0.75 × (TC) + 20

Example: Delegation cost for Product Class A conditional on counterpart being {{ agent_1 }}:

  • Expected(Delegation Cost to {{ agent_1 }}) = 0.75 × 50 + 20 = 57.50€
  • {{ agent_2 }} Cost = TC + 10 = 50 + 10 = 60€

2. Assuming the counterpart delegates to {{ agent_2 }} we are certain about our cost:

Delegation cost to {{ agent_1 }} (conditional on counterpart being {{ agent_2 }}):

Delegation Cost to {{ agent_1 }} = Transaction Cost + Human Agent Base Cost = TC + 20

Example: the delegation cost for Product Class A conditional on counterpart being {{ agent_2 }}:

  • Delegation Cost to {{ agent_1 }} = TC + {{ agent_1 }} Base Cost = 50 + 20 = 70
  • Delegation Cost to {{ agent_2 }} = TC+ {{ agent_2 }} Base Cost = 50 + 10 = 60
